# 测试分层

设计依据：§20（统一验收与 Agent 场景集）。

| 目录 | 内容 | 阶段 |
| --- | --- | --- |
| `integration/` | 跨模块集成测试 | P2 起 |
| `model/` | **独立参考模型**对照测试（页操作、RC 历史、图邻接、向量精确基准） | P2 起 |
| `crash/` | 崩溃注入与恢复验证（P3 要求至少 1 万次随机崩溃） | P3 起 |
| `isolation/` | 用户隔离与越权攻击用例（隔离失败属发布阻断项） | P1 起 |

## 原则

测试预期必须来自**独立参考模型**，不得照实现复制同一错误（§22）。
无排序的结果集按多重集比较；ANN 按召回与过滤正确性**分别**评分（§20）。
