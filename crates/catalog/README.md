## 状态说明

- **两条纪律**：字典表 = 普通表（经表引擎 + 事务 + redo）；目录接口**只读**（写走 DDL 路径）。
- **本切片（C1c）**：`catalog::dict` 是字典表格式常量的**唯一事实源**——
  - 12 张字典表（普通 9 张 + `public` 独有 3 张）的列/键定义（列定义引 `arch/03` §3.1.3）；
  - **列类型码**（1..12，本设计新冻结；12 = 字典内部 `BYTES`）、对象种类码
    （照 Oracle 预留 1..23）、索引种类码、命名空间、表选项码；
  - 自举条目数的定量（普通 **15** = 7 表 + 8 索引；`public` **23**）；
  - `self_check`（表名保留/列号连续/键指向有效列/自举表必有唯一索引/条目数定量）
    ——打开工作区时跑一遍，失败即拒绝打开。
- **`create`（C2a）**：建区期把**自举集**建出来（`目录详设` §5.1 的 ②③④）——
  7 张自举表的堆段 + 8 个自举索引的 BTree 段（**空树**：树头写段头扩展区）+
  引导页三件套（主块 1 / 副本块 256 / **文件头副本块 257**）。
  **直写、无 redo**：引导页本身不产生 redo；建区中途崩溃 ⇒ 未登记 `ws$` ⇒
  按"未完成创建"整体清除。**编号口径**：自举对象 `obj# = dataobj#`，自 1 起
  "表先索引后"连号（≤ 99）。返回 `BuiltDictionary`（条目 + 对象清单，供种子行用）。
- **未落地**：打开链与字典行缓存（C2b）、一致性核对（C2c）、
  `resolve`/`columns`/`object_version` 只读面（C3）、DDL 写侧与种子行（C4）。

实现进度请以仓库根 `README.md` 的阶段表为准。
