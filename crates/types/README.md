## 状态说明

实现进度请以仓库根 `README.md` 的阶段表为准。

设计依据（P2 切片）：

- **变长 base-100 科学计数法**（§6.5）：首字节 = 符号位 + 指数（偏移 65；
  负数指数取补）、数字位 `+1`/`101−值`、负数末尾标记 `0x66`、零 = `0x80`；
- **字节序 = 数值序**——索引比较无需解码（属性测试对随机会话全量验证）；
- **规范形式唯一**：前导零/尾零剥离、组内两位十进制、解码严格拒绝非规范
  形式（首位零组、尾零组、缺标记字节……）；
- **已知向量**与 Oracle `dump()` 对齐（1 → `C1 02`、0.5 → `C0 33`、
  -1 → `3E 64 66`、1234.56 → `C2 0D 23 39`）。
