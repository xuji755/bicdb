## 状态说明

设计依据（P2 切片）：

- **页头 68 字节** = 描述区 32 + 事务区 32 + 空间区 4；每多一个 ITL 槽 +24；
  **页尾副本**（4B）检断裂块、**CRC32C** 管完整数据完整性——`verify()` 先尾后校验和；
- **槽位目录** 2 字节/槽：14 位行偏移 + 2 位状态；上限 1023
  （行号 1..=1023，0 保留为"无"，与 `ROWID` 的 `row_id` 10 位耦合）；
- **`ROWID`** = `file_id` 10 位 │ `block_id` 28 位 │ `row_id` 10 位，6 字节小端；
  不含代次（文件重建换 `file_id`，永不复用）；
- **行格式**：行头 10B 固定部分 + NULL 位图 + 变长列偏移数组；**不设每列长度前缀**；
  `itl_slot` 是行→ITL→Undo 链条的第一环；**定长区宽度由列定义给出**（行内不存）；
- **片段链**：头片段（完整行头 + 6B 下一片段 + 数据段；**`row_len` = 整行长度**）、
  中/尾片段（短行头 10B）；**重组**校验整行长度；**转发指针**只有 6 字节。
