## 状态说明

实现进度请以仓库根 `README.md` 的阶段表为准。

设计依据（P2 切片）：

- **页头 68 字节** = 描述区 32 + 事务区 32 + 空间区 4；每多一个 ITL 槽 +24；
- **页尾副本**（最后 4 字节）= `page_type` + `mod_seq` + `page_lsn` 低位 2B——
  检出**断裂块**；**`checksum`（CRC32C，覆盖全页）**管完整数据完整性；
  两者互补（§5.8），`verify()` 先尾后校验和；
- **槽位目录** 2 字节/槽：14 位行偏移 + 2 位状态；上限 1023（与 ROWID 的
  `row_id` 10 位耦合：行号 1..=1023，0 保留为"无"）；
- **能推导的不存**（§5.2）：`free_start`、可用空间都不进页头；
- **每次修改必须 `seal()`**：写页尾副本 → 重算校验和。
