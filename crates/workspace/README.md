## 状态说明

实现进度请以仓库根 `README.md` 的阶段表为准。

设计依据（P1 切片）：

- 根目录名**由服务端生成**（`w-` + 12 位十六进制；`public` 为保留名），
  用户输入进不了路径拼接（`ISO` REQ-ISO-008；总体方案 §4）；
- 根目录与十个固定子目录权限显式收紧为 `0700`，**符号链接一律拒绝**；
- **FileIO 替换接口**（`ISO` REQ-ISO-007/008、总体方案 §17）：
  只有 `open` / `open_dir` 接受路径——符号链接一律**拒绝打开**，
  打开后按**已打开句柄**复核（`dev`/`ino` 与路径当前指向一致），
  破坏性动作（截断）只在复核之后；其余操作全走**不复用**的句柄——
  "以句柄为准，不以路径为准"在接口形状上成立。
  不硬编码 `O_NOFOLLOW` 一类 `fcntl` 常量（各环境数值不同，见 `io::os` 模块文档）。
  三个实现等价可替换：`OsFileIo`（生产）、`MemFileIo`（测试）、
  `FaultInjecting`（按第 n 次操作确定性注入 `Error` / `TornWrite` / `ShortRead`）。
- **身份路由**（`ISO` REQ-ISO-002/006）：`AuthenticatedSubject` 是路由的
  **唯一身份来源**（路由函数没有 `user_id` 参数——身份不在请求参数里）；
  `WorkspaceRegistry` 按 `(属主, 名称)` 解析，**他人的工作区与"不存在"
  给出不可区分的同一结果**（报"不存在"，不得报"无权限"）；
  跨属主同名合法、名字只在同属主内唯一。
