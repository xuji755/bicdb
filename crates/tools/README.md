# bicdb-tools

运维与诊断工具。设计依据：§17、`STO` REQ-STO-012。

| 工具 | 用途 | 阶段 |
| --- | --- | --- |
| `page_dump` | 转储页头 / 槽位目录 / 记录摘要（16 KiB 页镜像文件） | P2 ✅ |
| `db_check` | 检查器：页结构一致性、片段链、损坏识别与判定 | P2 ✅ |

## 状态

**v0.1 可用**（REQ-STO-012：P2 必须交付 `page_dump`/`db_check`，且先于完整 SQL 执行器）。

- **检查项**（本阶段 = 已定义部分）：两层完整性（页尾副本 + CRC32C）、
  初始化位、槽位目录越界、空闲区次序、按槽位状态解析记录、记录不重叠、
  片段位与槽位状态自洽；堆级**片段链**（链可达、尾端 NULL、无环、
  无自引用、多父引用）与**孤立片段**（警告）；
- **判定三档**（REQ-STO-012）：可用 / 可修复 / 不可恢复——P2 可达"可用/不可恢复"，
  "可修复"需修复路径（P3+），枚举先立；
- **只读纪律**：本 crate 不引入写路径；
- 退出码（稳定）：0 可用；1 有错误；2 用法/IO 错误。

页镜像 = N × 16 KiB 的连续页（工作区文件格式接入前，镜像即校验载体）。
