| 项 | 值 |
| --- | --- |
| 设计依据 | §8 崩溃恢复契约（存储架构 §11.1–§11.5，均已定案） |

## 状态说明

设计依据（P3 切片）：

- **记录（20B 头 + 块段 + 主段）**：`tot_len 4B │ lsn 6B │ txn_id 6B │
  op 1B │ flags 1B │ reserved 2B`；块段 = `blk_cnt` + 块引用（`flags 1B │
  rdba 5B │ chg_cnt 2B`）+ 块数据（`offset 2B │ len 2B │ after`）；
  主段**无长度字段**（由 `tot_len` 推导）；**只存 after-image**；
  **不带 CRC**（页尾校验覆盖每页）；
- **`rdba` 5B** = `file_id` 10 位 + `block_id` 28 位（比 PG 的 16B 省 11B）；
- **`op` 只是标签**（0x01 日志切换 / 0x02 检查点 / 0x10 页修改 / 0x30 提交 /
  0x31 回滚完成）——apply 路径唯一，幂等性由 `page_lsn` 判定；
  **空载荷记录（flags = 0）合法**（如回滚完成，信息全在头部）；
- **redo 页 512 B**（对齐文件系统原子写单位；页头 16B + 记录流），
  **分片头 12B**（`rec_id 6B │ frag_no 2B │ frag_cnt 2B │ frag_len 2B`）——
  分片解决的是**原子性**（系统操作的大记录跨页、单条仍原子），不是性能；
- **LSN = 日志流字节位置（分片头也算数）**；首片位置 = `rec_id` =
  记录头 `lsn` 字段（互为校验）；其余分片位置可推导、**不存**；
  新页起始 LSN = 上一页 + 512；
- **截断则整条丢弃**：分片序列不完整（末尾被截断）→ 该记录废弃，
  终止状态 `Truncated`（与"日志末尾不完整就停"同理）；
- **最坏单条 = 16417 B → 34 页 = 17 KiB**（测试钉住——组大小下限的来源）；
  "记录不得跨文件"在日志文件层接入时落实。
- **日志缓冲**（`buffer`，§11.5.5）：追加经 **latch 串行化**（跨页无额外代价）；
  **持 latch 不执行文件 I/O**（摘页在 latch 内、写与 sync 在 latch 外）；
  **组提交**：`synced_lsn ≥ 目标` 的等待者直接返回（共享同一次 fsync）；
  **刷盘失败即放回**（页只有在 sync 成功后才离开"未刷出"集合——
  否则失败一次就丢页）；被刷出的页不再接受追加（页序列永远是文件前缀）。
  缓冲是**固定容量的环形页池**（§11.5.5，照 Oracle log buffer）：
  空间判据 `end − synced ≤ 容量`（**耐久位之前不许覆盖**）、
  容量下限 **36 页**（最坏单条 34 页 + 余量）、默认 **256 页 = 128 KiB**；
  `flush_recommended()` = **1/3 触发**（`GroupWriter::append` 达阈值先刷盘、
  `BufferFull` 时"满则刷 + 重试"）；**刷盘成功后页缓冲回收进池**复用
  （复用边界 = sync 成功）；容量不足 ⇒ `BufferFull`（多写者切片改为
  条件等待 + `log buffer space` 同构诊断）。
- **日志文件**（`file`）：LSN = 物理字节位置（`偏移 = start_lsn − file_start`
  **互为校验**）；`FileLogSink` 顺序追加 + `sync_data`；**记录不得跨文件**
  （越界页直接拒绝：文件尾不足由上层切换逻辑处理）；`scan_log` 按**实际
  文件长度**扫描（崩溃后文件可短于声明容量）、空页即止、坏页即止，
  末尾残缺 → `Truncated`。
- **日志组与切换**（`group`）：LSN 跨组连续、组间在**页边界**相接；
  **切换记录**（`0x01`，组号 1B │ 新序列号 4B）写在新组第一条位置——
  组序与序列号在日志流内**自描述**；**序列号** = 上一当前组 + 1（首组 = 1，
  单调不复用）；**可复用判据** =（`INACTIVE` ∨ `UNUSED`）∧（非归档 ∨ `DONE`）；
  切换顺序：刷尽旧组 → 切换记录 **sync** → 发布控制文件（新组 `CURRENT`、
  旧组 `ACTIVE`＋`NEEDED`）——**切换记录先于 CURRENT 发布**；
  放不下下一条记录即**提前切换**（精确预检 `end_lsn_if_appended`，
  `write_record` 与预检共用同一分片规划）；无可复用组 ⇒ `SwitchBlocked`
  按"等归档 / 等检查点"两类暂停；
  `publish_checkpoint` 把"组结尾 LSN ≤ 检查点低水位"的 `ACTIVE` 组降为
  `INACTIVE`，与低水位**同一次控制文件更新**（§11.9 发布纪律）；
  `open` 扫描已用组重建结尾 LSN，当前组从**下一页边界**续写
  （已刷页不改写）；**成员镜像（2 份）随后**——`STALE` 落点待定案。
- **重做应用**（`apply`）：**apply 路径唯一**——块引用定位 → 读页（两层校验）
  → `record.lsn > page_lsn` 才写（否则跳过，含乱序/重复）→ 先逐变更写字节、
  **后重读页头**只推进 `page_lsn`/`mod_seq`（变更可落在页头字段上）→
  seal → 定址写；跨块原子性由**幂等重放**保证（块间失败重跑收敛）；
  页损坏按损坏处理（不跳过、不静默）。
- **恢复的重做阶段**（`recovery`）：`online_groups` 扫描已用在线组并**按序列号升序**
  （= 日志流顺序）；`redo_from(start_lsn, resolver)` 从检查点 LSN 起逐条
  `apply`（起点之前的记录跳过不应用）；报告 `log_end`（在线组已写尽头
  = 撤销阶段起点 = 恢复后写方续写位置）；重复重做全部跳过（幂等）。
