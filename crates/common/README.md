## 状态说明

实现进度请以仓库根 `README.md` 的阶段表为准。

设计依据（P2 切片）：

- **错误码**：`BIC-<五位数字>`；九个与 Oracle 对齐的常用码**冻结**（测试钉住，
  "只增不改、不复用"），新码自 `BIC-10000` 起；
- **四类判定即字段组合**（`API` §0.4 的表做成了 `EngineError::advice()`）：
  可重试冲突 / 资源拒绝 / 已中止事务 / 提交结果未知——**不设冗余 `class`
  字段**，字段是唯一事实源；
- **`Lsn` 与 `CommitSeq` 是两种类型**：`CONV` §3 要求"混用无法通过编译"——
  由 `compile_fail` 文档测试机械保证；
- **页校验和 = CRC32C**：覆盖全页、`checksum` 字段置零后计算；增量计算器
  （`Crc32c`）避免为页校验复制 16 KiB；正确性由**独立逐位模型**与公开向量
  （"123456789" → `0xE3069283`）双把关。
