## 当前实现概览

- 关系内核已具备堆表、B+Tree、WAL/Undo、崩溃恢复、事务与检查点。
- SQL 支持当前手册列出的 DDL/DML、聚合、两表连接、集合运算和索引访问路径。
- 管理面支持用户、私有工作区、本机口令认证、owner 绑定、字典只读查询和空结构模板。
- 服务可保持多条隔离连接；语句由单实例执行器串行调度。
- 图模块已支持原生邻接、限定 Cypher 读写、有界路径、属性索引、`GRAPH_TABLE` 和图全文索引。
- 图全文支持 BM25、节点/关系范围、固定 JSON 路径、strict/eventual 查询及 manual/batch/定时维护。
- TCP、并行语句执行、完整 Cypher 25、APOC/GDS、图向量/空间索引及生产规模性能验收尚未完成。

## 文档口径

- 存储层采用原地更新、Undo 与 WAL；业务版本由上层行或节点表达。
- 工作区是隔离边界，`public` 是共享只读区，不提供跨用户授权。
- 设计文档描述的阶段目标只有在使用手册或功能指南列为“已实现”时才可按现成功能使用。
- 图功能提供受控子集，不等同于 Neo4j、PostgreSQL AGE 或完整 openCypher 的兼容实现。
