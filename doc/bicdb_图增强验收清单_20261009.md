当前整体目标：完成 bicdb 图数据库存储、检索、索引增强，参考 Neo4j 数据结构及 Rust daemon 检索算法，禁止修改 Neo4j 数据。下表是当前验收状态，不把通过某个阶段测试当作整个目标完成。

## 与冻结 GRP 规格的关系

`doc/spec/GRP.md` 保留了原目标，用户后来明确要求参考 Neo4j / Rust daemon，因此多标签、较丰富 Cypher、独立实体记录、100 MiB 和 16 跳默认值已有实施偏差说明。不能通过改写原规格把未实现能力抹掉，也不能把用户要求扩展的语言能力当成“违反旧禁止清单”。

需要继续核验的原规格条目包括：

- GRP-002 / 010：物理 type-3 段、type-5 页、稳定目录、端点 ROWID 行锁、undo/CR/WAL 及段访问内核已实现，见[内核与接入边界](bicdb_邻接页与事务访问内核_20261009.md)。显式升级的 SQL 图已使用 v3 权威邻接；页外大属性、入口/反向/定位树及索引/全文同事务编排和显式迁移已接入，见[SQL 升级](bicdb_SQL邻接存储升级与联合提交_20261009.md)。默认新图已使用同事务 v3 创建，非活动路由的验证替换与旧 v1/v2 迁移的 12 组正式填充阶段刷盘崩溃/恢复已完成，见[迁移接管与恢复](bicdb_旧图迁移接管与分阶段恢复_20261009.md)。多连接会话隔离和提交栅栏已验收；节点 Move、语句并行执行、真实 SQL 端点锁等待交错和回收仍待完成。
