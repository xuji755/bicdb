# 图语句时间预算（2026-10-09）

本阶段为图查询、图写入和图全文维护增加同一个语句时钟，防止子查询或访问入口重置时间上限。超时返回资源错误，普通图写语句不发布其未提交变更。所有写入及恢复验证使用隔离的 bicdb 合成实例，未连接 Neo4j。

## 配置与请求

```ini
[graph]
max_elapsed_ms=60000
```

范围为 `1..60000` 毫秒，默认 `60000`，重启生效。配置文件、`-c graph.max_elapsed_ms=...` 和受信任 Session 政策使用相同范围，STATUS 显示 `graph_max_elapsed_ms`。

```sql
PROFILE CYPHER kg 'MATCH (a:Hub)-[:LINK]->(b) RETURN b.name'
  BUDGETS '{"max_elapsed_ms":1000}';

SELECT g.name FROM GRAPH_TABLE(kg, :query BUDGETS :budgets
  COLUMNS (name VARCHAR2(128))) g;
```

请求只能降低工作区政策，不能提高上限。0、负数、非整数、未知字段或超过工作区上限的请求拒绝。错误不会改变下一条语句的政策，也不会影响普通 SQL 或事务清理。

## 时钟范围

- 使用单调时钟，从图 SQL 执行入口开始；内层 Cypher 解析、图元数据读取、绑定、暂存图构造、原生记录和索引读取、遍历、表达式、中间行及结果转换沿用该时钟。
- CALL、EXISTS、UNION 和索引 provider 不能重启计时。请求收紧保留原来的起点，只降低允许的总时长。
- 一条 SQL 的 GRAPH_TABLE 来源在物化阶段共用起点，每个来源可进一步降低自己的上限；内层来源结束后恢复外层政策。结果编码也检查工作区时钟。外层普通 SQL 的解析、绑定、后续联接/聚合、结果传输不在整个图时钟的保证范围内。
- 图 DDL 将同一截止点传递给目录事务；字典写入、访问树构造和全文记录填充在安全点检查，最后一次检查发生在提交前。
- 全文 SYNC、WAIT、REBUILD 和服务定时维护使用工作区政策。每次后台 poll 使用自己的时钟，原有批次范围、暂停和失败重试机制保留。
- 独立核心图执行/BFS API 使用相同默认预算；接受已有 Deadline 的 API 可继承上层时钟。直接调用模板导出/初始化等受信任管理 API 尚未统一安装图语句时钟，不作为这些 API 的时限保证。

这是安全点检查的协作式超时。单次文件读取、物理 SQL 扫描、WAL 刷盘、提交或回滚不能中途抢占，所以响应墙钟时间可能超过配置值。上限不是严格的客户端响应 SLA，也不是一般 SQL 超时参数。

## 提交与回滚

普通图写入先暂存，检查通过后才持久化；记录删除、更新、插入和原生索引维护检查同一时钟。超时走既有事务/语句回滚路径，保留外层显式事务此前成功的 SQL。回滚不受已经过期的时钟取消，不能留下半清理事务。

不在成功提交之后再以时间过期返回写入失败。全文 WAIT 在每个成功批次后沿用已经发布的 journal 镜像，避免重读时超时，把已经耐久的最后一次确认误报为失败。若一个 SYNC/WAIT 已完成若干批次而后续批次超时，前面成功批次仍保留；超时批次不推进确认水位，下一次维护继续处理剩余事件。图元素 ID 的耐久预留仍可留下跳号。

回滚测试同时复现并修复了目录对象号问题：若失败 DDL 在事务内预留新的对象号批次，回滚必须清除内存批次，否则后续提交对象可能与重新读取的 seq$ 高水位发生重复。目录点查和范围查也必须跳过死索引项、复核实际行键；回滚遗留的旧 ROWID 可能已经被其他行复用。普通用户表索引仍使用其原来的行复核路径。

## 诊断与验证

PROFILE 在既有列之后追加 `elapsed_ms`（第 14 列，0 基下标 13），旧列顺序不变。每个访问路径行重复展示整个 Cypher 执行阶段的累计时间，不能把各行相加。该值不包括客户端传输和成功提交之后的工作。

验证覆盖：过期时钟不能重启、慢 provider 的相关子查询共享时间、暂存写入失败、原生 CYPHER/GRAPH_TABLE 请求超时、政策与事务恢复、PROFILE/STATUS、单个全文批次超时后水位保持及恢复维护、部分 DDL 写入后的回滚、跨对象号批次后连续建表和重启。最终日志、固定测试程序哈希和部署范围见[证据目录](evidence/bicdb-graph-deadline-20261009/README.md)。

实际执行器内存计账、跨 GRAPH_TABLE 来源的混合工作总计数和显式部分结果协议仍待实现。专用邻接段、增量写规划、并发端点锁、图元素句柄/受管引用、回收与大型性能验收继续按[整体验收清单](bicdb_图增强验收清单_20261009.md)推进。
