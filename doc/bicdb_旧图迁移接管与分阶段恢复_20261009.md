# 旧图迁移接管与分阶段恢复（2026-10-09）

## 升级行为

SQL 仍为 `ALTER GRAPH kg UPGRADE STORAGE`。已使用 v3 manifest 的图保持幂等；旧 v1/v2 数据不会因查询或服务重启被自动迁移。

旧图已有四个预建物理路由时，原实现会直接报“graph physical routes already exist”，导致这种合法准备状态无法升级。现在先验证完整路由的 graph 属主、类型、描述、列定义及段头归属，再在最终迁移事务中替换为四个新对象/新段。节点转换、活边填充和 v3 manifest 在同一事务发布；属性索引、全文对象及源队列保持逻辑身份。

这是对已有非活动路由的受验证接管，**不复用原段或原路由对象号**。即使先前失败写入在原路由留下 redo-only B-tree 候选，新的填充也不会遇到伪“已存在边 ID”。旧路由内容不作为源数据、不被直接删除覆盖；源仍是经过完整校验的旧 manifest 和图记录。四路由缺失、错误描述、错误类型/归属等都会拒绝，SQL 在准备其他索引 DDL 之前先做这项校验。

缺少旧 ordinal/访问派生树的图仍可能有独立的准备 DDL 提交，沿用此前边界；最终权威布局发布只有一笔迁移事务。本阶段不是全面在线并行迁移或用户事务内迁移；仍需空闲用户事务状态并遵守单写者约束。

## 节点迁移准备

`StorageImage::adjacency_migration_patch` 是 SQL 和故障验证共用的准备算法：保留旧 authority header，生成/比较节点记录，撤回旧边记录或旧 v1 顺序块，随后由同一事务的 NativeAdjacency 写入真实边并替换 manifest。

旧实现先编码所有节点和全部旧格式边，再丢掉编码好的边记录；现在只编码迁移需要的节点，边由原生数据口编码。节点、边及载荷预算仍分别在准备/实际写入路径检查，节点校验和锚点保持固定长度。中间“只有节点、header 仍标注旧图”的状态只存在于未提交迁移事务，不能独立发布成可读图。

`NativeAdjacency::apply_records` 作为可信内核接口用于这些阶段；它要求自己的事务视角，但不替调用方验证逻辑图约束或提交。SQL 调用方完整校验源图、解析受管路由，并在填充成功后发布 authority。这个接口不对应允许用户直接改受保护 graph heap 的 SQL。

## 分阶段真实恢复

隔离合成 v1 checksum/chunks 与 v2 实体记录实例，分别采用没有预建路由/已有完整非活动路由两种状态；在以下三个阶段实际刷新 WAL 与工作区页后退出进程 99，绕过析构及 COMMIT：

1. 已转换节点并撤回旧拓扑记录，尚未写入任何边。
2. 已插入首条大属性边，包含 overflow/source/locator/reverse 的实际写入。
3. 全部边和带有效 SHA 的最终 v3 manifest 已写入。

共 2 × 2 × 3 = 12 个故障实例。每例重启后核对旧 heap 字节、路由集合、六张目录计数、逻辑 ID/属性及全文状态，随后用正式 SQL 重试升级，再验证已有全文查询与后续内容变更维护。

故障子进程使用正式 DDL 迁移路由回调、共用节点准备算法及 NativeAdjacency 数据口。注入不依赖生产环境变量后门，不宣称已覆盖迁移每一条 WAL 的任意断点或数据库设备故障。v1 是按既有 checksum/chunks 格式构造并通过当前兼容解析验证的合成实例；真实留存旧程序生成数据的升级用例另行保留。

还验证了在旧完整路由上真实写入原生节点/边再回滚，产生未撤销 B-tree 候选后，正式 SQL 可以安全替换、一次提交完成升级、保留旧视图和全文队列；伪造 descriptor 则在预约提交序号前被拒绝。

## 限制与证据

普通写入仍完整图验证/暂存，迁移仍需完整读取源。旧段及旧候选没有物理回收，这里降低的是无用旧边编码与失败路由复用风险，不是整图增量写规划或大图性能验收。

实际全量、兼容回归、发布/运行文件核验见[本阶段证据](evidence/bicdb-graph-legacy-migration-20261009/README.md)，其结论只覆盖所列边界。下一阶段继续 SQL 并发交错、局部增量写入、一般 Move/GC、图句柄与受管引用、内存/部分结果及规模化验收。没有连接或修改 Neo4j；生产工作区不执行自动旧图升级。

后续阶段已将写语句改为首次原值 journal 与净变更局部规划，并修复 v1 格式转换误入全文源事件队列的问题，见[实现与最新证据](bicdb_图语句变更集与局部写入规划_20261009.md)。本文件保留迁移接管阶段的历史范围，完整源加载/逻辑投影等余项仍在。
