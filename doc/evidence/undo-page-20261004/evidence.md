# 证据包：Undo 页与 Undo 记录的结构定案（Oracle 参照）

模块：存储架构 §4.6.1（Undo 页）/ §4.6.2（Undo 记录）　对应：待冻结项 #8（Undo 部分）
核验日期：2026-10-04　原始输出：`raw/01–06`（同目录）

## 结论

1. Oracle 的撤销块 = **专用块头 `KTUBH` + 记录偏移表（`idx`，每项 2B、自块底向上）+ 记录区
   （自块尾向块头写入）**；其字段与我们通用页头的逐项对照（§4.6.1 既有表）成立。
   本次下钻补到两条此前未覆盖的机制：
   ①**超长撤销记录跨块**（Oracle8+）：一条记录可跨多个撤销块，分为**头片/尾片**，
   由 `KTUBU.flg` 的 **0x01（多块撤销头）/ 0x02（多块撤销尾）**标识；
   ②**UBA = DBA + 块序列号 + 记录号**——块序列号在**区切换**时递增，用于判定 UBA 是否仍然有效；
   记录号单调性参与 redo↔undo 配对校验（`ORA-600 [4137]` / `[4194]`：新增记录号必须等于
   块内最大记录号加一）。
2. Oracle 撤销记录（`KTUBU`：`obn`/`obd`/`tsn`/`dba`/`opc`/`slt`/`rci`/`flg`/`wrp`；首记录另含
   `KTUBL` 的上一控制 UBA/SCN）逐项对照结论：**对象/表空间标识、事务表槽号、XID 代次三项我们不要**
   （定位靠 `rowid`、代次靠 `txn_id` 三段式、链是事务私有的）；`dba`+`rci` **合一为 `prev_undo` 6B**；
   `flg` 的**多片标志采用**（flags 1B）。链的回滚语义一致：Oracle 自 `IRB` 起沿 `RCI`/`DBA`
   逆序应用——我们沿 `prev_undo` 走到链首（本来就是"与产生顺序相反"）。
3. 两块"代次/校验"机制可以用**更少的部件**替代：UBA 的 `seq#` → 由 §4.6.5 回收判据
   （"有引用的 undo 必存活"）替代，回溯时的占用者核对由 `txn_id` 检查兜底（§12 的回溯表）；
   单调记录号 → 由**页级 LSN 守卫**承担重放幂等。**本次另发现一处需要补的口子**：
   推导"跨页行删除前像 = 头片段字节"时，**片段链身的存活**必须与最老快照挂钩，
   而 §6.4 现文未显式封顶——已登记 **待冻结项 62**（P2 细化时补判据）。

## 本项目自主决策

1. **多片撤销记录照 Oracle8+ 的形态**：放不下一页时沿 §6.3 的行片段链跨页——首片带"多片头"、
   尾片带"多片尾"（`flags` 1B）；**`prev_undo` 恒指向首片**；上限照 §6.3（64 片）；
   **回收以"记录"为单位**（片不单列，判据作用于所属事务，§4.6.5）。
2. **不要 `obn`/`obd`/`tsn`/`slt`/`wrp`/`seq#`/`rec#`**：定位靠 `rowid`（+块头对象号，诊断用）；
   代次在 `txn_id` 三段式（事务表侧）；有效性靠回收判据 + `txn_id` 检查；重放幂等靠 LSN 守卫。
   `dba`+`rci` 合一为 `prev_undo` 6B（第三段 = **页内槽号**，对齐 D-06 与 ROWID 结构）。
3. **删除前像的跨页行形态**：取**头片段的全部字节**——片段链身不在载荷内（删除未修改它们）；
   其存活依赖待冻结项 62 的判据落地。
