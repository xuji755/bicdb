  ✅ 答案要点
     日志切换相关等待事件：1）log file switch completion：等待日志切换完成（可能因为归档慢或日志组不够）；2）log buffer space：日志缓冲区满，等待LGWR写入；3）log file switch (archiving needed)：等待归档完成才能重用日志；4）log file sync：等待LGWR将提交日志写入磁盘。解决方法：增加日志组数量、调整日志大小、优化归档速度、调整LOG_BUFFER。
