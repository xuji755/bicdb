### detail 3259400 绑定变量窥探机制与局限

  📖 实体详情
  类型: bic_agent_KnowledgeEntry,SyncEntity
  名称: 绑定变量窥探（Bind Variable Peeking）机制与局限
  ID: 4:8ed6c541-fe08-4ade-ae68-a79bf45316f4:3259400

  ── 描述 ──
  早期版本中使用绑定变量时优化器不会使用柱状图，而用默认的选择性值判断。9i+ 的绑定变量窥探可在硬解析时借助柱状图选择较好的执行计划，但它只在 SQL 第一次执行、执行硬解析时进行；由于后续 SQL
  都使用绑定变量并被认为是安全的，会复用共享游标，不再窥探。因此这条 SQL 可能有两种执行计划（索引扫描或全表扫描），选择哪一种完全取决于硬解析那条 SQL 的绑定变量值，优化器无法做出最佳选择。

  ── 摘要 ──
  9i 及更高版本的绑定变量窥探只在 SQL 第一次执行、硬解析时结合柱状图选择计划；此后所有 SQL 复用共享游标不再窥探，计划固定为首次硬解析时绑定变量值对应的计划。
