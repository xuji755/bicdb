  ✅ 答案要点
     早期版本中使用绑定变量时优化器不会使用柱状图，而用默认的选择性值判断。9i+ 的绑定变量窥探可在硬解析时借助柱状图选择较好的执行计划，但它只在 SQL 第一次执行、执行硬解析时进行；由于后续 SQL 都使用绑定变量并被认为是安全的，会复用共享游标，不再窥探。因此这条 SQL 可能有两种执行计划（索引扫描或全表扫描），选择哪一种完全取决于硬解析那条 SQL 的绑定变量值，优化器无法做出最佳选择。
