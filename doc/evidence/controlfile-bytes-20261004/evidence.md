# 证据包：控制文件字节布局定案（Oracle 参照）

## 结论

1. Oracle 控制文件 = **带类型号的记录段**；第一层划分是**复用方式**——
   非循环（库信息、检查点进度、redo 线程、日志文件、数据文件、文件名、表空间、临时文件）
   vs **循环**（日志历史、归档、备份系列，写满覆盖最旧）。记录类型有完整枚举
   （`X$KCCCF.INDX`；字段布局见 `kcc3.h` 一族，如数据文件记录含文件号、检查点 SCN、文件大小）。
2. Oracle 的 `Seq#`（控制文件序列号）是**版本号**：每次控制文件头更新 `+1`，**并同时写入每个
   数据文件头与日志文件头的 "Control Seq" 字段**——启动时比对以检测"文件与控制文件不是同一版本"。
3. 我们沿用"带类型号记录 + 非循环/循环划分"，并明确两条取舍：
   ①**不做跨文件的 `Control Seq` 比对**——我们的分工是"创建时属性在控制文件、可变量以文件自身为准"
   （§2.6），版本错配的残余窗口由 **redo 幂等重放**收敛（§2.6 末节），不需要第三个版本字段；
   ②**`seq` 的作用域改为"两副本之间"**——副本写有先后协议（先 A 后 B），开档取"有效且 seq 较大"。

## 本项目自主决策

1. **控制文件 = 20 页 × 16 KiB = 320 KiB**（页对齐；#45 的 284 KiB 估算是紧凑排布）：
   页 0 = 文件头（段偏移表 8 项 × 16B + **固定偏移 132** 的单条 undo 记录 522B）；
   页 1 = 固定段（工作区条目 64B │ 检查点进度 48B │ Redo 条目 128B │ 归档记录 320B）；
   页 2–19 = 数据文件记录数组（1024 × 280B = 2 + 1 + 1 + 2 + 6 + 8 + 4 + **路径 256B**）。
2. **每页 = 页头 24B + 页体 + 页尾校验 4B**（照数据页惯例）：页头 = magic 4B │ seq 4B │
   page_no 2B │ payload_len 2B │ copy 1B │ flags 1B │ 保留 10B。
3. **更新协议（单连续区间 ≤ 512B）**：①写 undo（旧值）→ ②写目标字节范围 →
   ③写页 0 的 `seq`（+1，作为该次更新的"发布"）→ ④清 undo（旧值长度 ← 0）。
   四种崩溃点全部可判（undo 空/非空 × 范围新/旧）；"多退一次"可容忍（幂等状态发布，§5.11）。
4. **副本选择** = 页校验通过 ∧ undo 为空（或已按记录回滚）∧ **seq 较大**。
5. 数据文件记录 24B 非路径部分 = `file_id 2B │ role 1B │ status 1B │ flags 2B │
   创建时大小 6B │ 创建时间 8B │ 保留 4B`。Redo 条目 128B = 头 4B（组数/成员数/当前组/保留）
   + 8 组 × 12B（序列号 4B │ 状态 1B │ 归档状态 1B │ 保留 6B）+ 保留 28B。
   归档记录 320B = 归档模式 1B │ flags 1B │ 最后归档序列号 4B │ **归档目标路径 256B** │ 保留 58B。
