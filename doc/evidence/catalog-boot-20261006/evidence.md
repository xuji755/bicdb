## 3 落到本库的推论（写进设计 §2）

- **副本必须与主副本空间分离**（不同块带）；相邻块的两份副本**不构成冗余**。
- **file 0 专用排布**：`[0, 4 MiB)` 核心元数据带（主：块 0 文件头、块 1 引导页；其余预留），
  `[4 MiB, 8 MiB)` 副本带（引导页副本 + **文件头副本**——头被毁同样需要恢复）；
  位图区与数据区**顺移到带后**（file 0 专用公式）。
- **保留重建兜底**（E2）：主副皆坏 ⇒ 扫段头页 + 控制文件重建（引导页四要素可从段头页读出）。
- **预留带不写入**（稀疏，读为零）：磁盘占用不变，只是**地址空间预留**。
