**编码期发现与修正**：

1. **`fcntl` 常量随架构不同，不可硬编码**（2026-10-04）：**arm64** 的
   `asm/fcntl.h` 自带定义（`O_NOFOLLOW = 0o100000`、`O_DIRECTORY = 0o40000`），
   **x86_64** 走 `asm-generic` 的经典值（`O_NOFOLLOW = 0o400000`）——
   与 OS / 内核版本**无关**（192.168.30.33 = RHEL 7.6 / 内核 3.10 / x86_64
   实测经典值；开发机 = Ubuntu 24.04 / 内核 7.0 / aarch64 实测新值；
   两机年代相隔近十年）。**实测同一数值在另一架构上静默跟随符号链接**
   （0o100000 在 x86_64、0o400000 在 arm64 均被当作 `O_LARGEFILE`）。
