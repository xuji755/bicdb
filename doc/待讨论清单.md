### C. 端到端场景走查 ✅ **已做**（`端到端场景走查_v0.1.md`）

| 4 | `memory_version` 是"内容快照"还是"一次变更事件"？ | 中 | ✅ 已修：明确为**事件**（内容 + 状态都在里面） |

## 三、已经结掉的重项（供追溯）

| 项 | 结果 |
| --- | --- |
| **页类型设计** | **14/14 全部已定**（页头一致 68B，页体按类型各自定义） |
| **REDO 页** | ✅ 必须有页结构——理由是 **redo log buffer**；记录可跨页，靠分片头串联 |
| **字典表** | ✅ 十一张（自举七 + `stat$` + `public` 独有三）+ 一张固定表 `file$` |
| **`obj$` / `seg$` 分层** | ✅ 对象层 / 段层 / 物理层；`seg$` 的判据是**持久性** |
| **固定表 `file$`** | ✅ 权威在控制文件；**不是视图**；不加 `X$` 前缀 |
| **临时段** | ✅ **内存池**（参照 Oracle 的 sort extent pool）——原先写的正是它 7.3 之前的老机制 |
| **延迟块清除** | ✅ 采用**延迟日志版**（标准版的 `SELECT` 会写块，违反"读路径不产生同步写"） |
| **`txn_id`** | ✅ 三段式 `usn 8 \| slot 8 \| wrap 32`——它只要求**实例运行期内不重复** |
| **可见性 / MVCC** | ✅ §12 成立；`ITL 覆盖` op 是长查询能读到"已删除且槽位被复用"的行的前提 |
| **权限模型** | ✅ 参照 PG 的**形状层**（不取授权矩阵）；`public` 有**专用过滤层**与**标准接口**写侧 |
| **`public` 的过滤层** | ✅ 一**层**而非"每处检查一次"；行级过滤必须是**扫描范围的一部分** |
| **类型编码** | ✅ 照 Oracle 内部实现；判据是**确定性**而非"LLM 与否" |
| **JSON** | ✅ 参照 PG 的 `jsonb`；**不学它的偏移/长度折中**（那前提是通用压缩器，我们没有） |
| **记忆模型** | ✅ 六条路线对比后优选；判据"**能力归库，策略归 agent**" |
| **属性图（GRP）** | ✅ 边界已定（**≠ `derived_link`**）；图 = 表 + 伴随对象；边 = 邻接段条目（`edge_id` 对外 / `edge_seq` 聚簇键）；变长遍历 = **trail**；引用登记 `ref$`；截断状态显式 |
| **外部资产（AST）** | ✅ 文件（不可变、非事务）/ `asset$`（事务状态机）/ `ref$`（登记，推广到表行）三事分界；`staging` 是已提交的行；七步协议（内容先于名字、名字先于元数据）；回收 = 最老快照 + 读取租约 + 备份（并入租约）；不做任何去重 |
| **锁与事务的存储实现** | ✅ 补全：事务生命周期（开始 / 语句回滚点 / 回滚 / 槽耗尽，§4.6.6）+ 行锁协议（获取 / 等待 / 唤醒 / 死锁接口 / 对象锁，§5.4.2）+ latch 与 lock 的分工；**并修正提交次序**——提交记录先入日志流，再标记可见，再唤醒（§11.1.1 次序表：原序给等待者留了一扇"依赖链断裂"的窗口） |
| **SQL 引擎** | ✅ 五阶段（Raw AST 不碰 Catalog → Binder → 逻辑 → 物理 → 执行）；**扩展面不设旁路**（图/ANN/JSON/向量全汇入同一管线）；名字解析三格 + 保留清单；语句正反清单（含"连 `ALTER TABLE` 都不给"的理由）；计划缓存键（工作区为首项）；优化白名单 + 四条不变量；**待冻结项 47/48 落地** |
| **访问协议与 SDK** | ✅ 四层交付（内核→SDK→CLI→适配层，适配层只翻译）；**身份不在参数里**（请求/游标/MCP/SQL 文本四处置同一纪律）；封套字段 + 四类判定的字段组合；**`idem$` 与"提交结果未知"的免费消歧**；命令族闭集；分页游标三绑定；围栏契约先行 |
| **运维与备份（OPS）** | ✅ 管理面闭集（零业务内容接口）；脱敏纪律（指纹代正文）；`audit` 表（属主只读、无 DML 入口）；**备份自描述**（落待冻结项 26）；**归档保留双条件**（落 13）；"备份覆盖全部、PITR 只覆盖 redo 保护数据"的准确口径；诊断转储两段式（导出须属主授权） |
| **非功能（NFR）** | ✅ 六族 40 条：三层门槛（P0 数值/P7 基线/门禁只增不删）；读路径唯一共享点的点名（快照注册表）；九项攻击面落点表（新增"不跟随符号链接"）；关键任务资源保留逐项；ADR 落点 `doc/adr/`；四个参考模型清单；CI 三档与重跑触发表；第三方库红线 |
