# 邻接大属性与受管路由（2026-10-09）

本阶段继续落实权威邻接 SQL 接入的前置能力：实现大属性/长关系类型编码、固定大小的快照链入口元数据，以及受管邻接段/源入口/边定位/反向路由的原子目录事务。全部测试使用独立合成 bicdb 实例，未连接或修改 Neo4j。

**SQL 图当前仍使用 v2 heap 记录。** 没有把存在四个空路由误当成迁移成功，普通建图/写图也没有自动创建它们。版本选择、实际写入/查询适配和旧图迁移继续实施；本阶段不宣称 GRP-002/010 完整完成。

## 大属性与稳定定位

`graph::adjacency_record` 将逻辑边编码为 type-5 边记录。载荷前缀为 57 字节：版本魔数、内联/外部标志、逻辑源/目标 ID、文档字节数和 SHA-256。校验和绑定边 ID、逻辑端点、物理源/目标 ROWID 和完整文档，不能将文档挪到另一个边或端点后继续通过验证。

文档仅含完整 `label` 和 `properties`，不把边的拓扑字段保存为独立 heap 权威边。规范 JSON 保留嵌套对象、数组、null、Unicode 和受现有 NUMBER 范围支持的高精度数值。不是对数值精度范围的新放宽。

文档不超过 4096 字节时可以内联；更大文档使用 kind-3 ordinal 域的校验和与 4096 字节分块。最多 1023 个文档块，并服从调用方文本字节预算；取得范围之前先检查声明长度。读取严格核对 ID、块数、连续键、每块长度、两份校验和、字段形状、类型名和规范序列化。不能用缺块/额外块或另一个 ID 的数据补齐结果。

type-5 的关系标签字段上限是 255 UTF-8 字节。更长类型在页头使用空串哨兵，完整名称保存在文档中，不能截断；它与真正的空类型不混淆，逻辑编码拒绝空类型。

当小边记录更新后不能在既有页增长时，`Placement::External` 可将载荷缩为固定描述符，保留目录序号和端点。实际满页测试覆盖内联扩展失败、外部编码更新成功、保持定位和撤销恢复原值。SQL 适配器还需负责在同一事务中发布外部块/描述符、删除旧块及发送全文事件；本阶段不独立提交这些对象。

## 入口元数据与索引键

`SourceEntry` 为固定 32 字节，记录源顶点 ROWID、头/尾页地址和最大已连接边 ID。它必须保存为普通受保护 heap 行，并由源入口 B-tree 定位该行，读取时使用 CR。B-tree 直接保存一个可变头地址不能提供旧快照入口，因此不采用这种表示。

源入口 ordinal 使用独立 kind-4 域，不与 node/chunk 或大属性域混合。源键和边定位键采用保序 6 字节编码。边定位树的值是实际稳定边 ROWID，不能沿用 v2 将逻辑 ID 填入 ROWID 字节的伪地址。

反向树键含目标 ROWID、类型选择器、源 ROWID 和边 ID，值为实际边 ROWID。短类型使用带标签的转义 UTF-8，保留 NUL；长类型使用另一标签的 SHA-256 选择器，防止覆盖后缀导致旧版可用的长名称超出 B-tree 键长。长类型只是候选，回表必须复核完整名称，哈希碰撞不能判定类型相等。按端点和无类型前缀仍可枚举两种选择器。

## 受管路由目录事务

目录新增四个伴随种类：GRAPH_ADJACENCY=261（type-3 段）、GRAPH_SOURCE_ENTRY=262、GRAPH_EDGE_LOCATOR=263、GRAPH_REVERSE=264（三个 B-tree）。按图对象拥有，登记 obj$/ind$/icol$/seg$/stat$，使用保留名称和专用描述符。普通 heap DML 忽略这些伴随对象，普通 DROP INDEX 禁止单独删除；DROP GRAPH 同事务级联其登记。

`ddl::graph_physical_routes` 只读验证完整集合、种类、状态、列定义、描述符、段类型和对象归属。半套、重复或伪造路由报错，不静默创建或覆盖。对非 B-tree 的 range 读取明确拒绝。

`ddl::create_graph_physical_routes` 在既有目录事务内创建全部四个对象，并执行 populate 回调；回调得到同一 buffer pool、WAL、undo 和原始事务，可写图数据与权威版本标记。回调失败走普通完整回滚；DDL 时间限制仍在最后提交前检查。现有路由拒绝重复创建。

成功创建空路由只代表底层资源就绪，不能选择 v3 权威。原生 SQL/快照模板继续以 v2 manifest 解读图。模板导出验证非活动路由但不复制物理对象号/地址，后续目标自行重建。

## 验证及接入余项

专项涵盖 200 KB 嵌套属性、4080 字节长类型、UTF-8 字节边界、高精度数值、内联/外部转换、伪造端点和 ID、坏块/长度/校验和、预算预检、固定元数据及反向键。目录测试涵盖创建、原始 heap 元数据快照更新、读己所写、回滚、同池目录重开、单独删除禁止及图删除级联；同池重开不冒充整个进程恢复。

独立真实文件实例另覆盖非活动路由下的 CYPHER/逻辑模板/重启兼容，以及崩溃恢复：子进程在四个路由及非法新权威标记都已写入并刷盘后直接退出，父进程重新打开实例，通过真实 WAL redo/undo 恢复原来的 SQL 图和无路由状态。崩溃辅助测试在普通列表中标为 ignored，但由父用例实际启动，不把辅助函数重复计为通过。

## SQL 接入的事务边界（待实现）

版本入口必须先读取普通图 manifest 行，再选择 v2 或 v3。v3 标记需保存本图的完整路由身份与固定段地址，且核验所有权；不得根据当前目录中存在空路由直接切换，或让旧快照改用后来重建的段。启用 v3 标记前，`NativeGraphReader`、整图写入加载、严格全文读和带数据模板导出都必须能读取该格式。

节点的 kind-1 校验和行长度固定为 32 字节，可作为首版物理锚点；通过本图 ordinal 索引与同一快照找到该行。遇到转发行不能仅拿最终目的 ROWID 替代稳定身份，须按节点 Move 的明确协议处理。codec 中的哈希验证不能代替图归属及逻辑端点核验。

出边由源树取得普通 `SourceEntry` 行，再按 CR 的头地址遍历邻接页；入边由反向树取得候选并回表复核类型、端点与可见性；单边按定位树取得真实边 ROWID。陈旧 B-tree 候选、不可见行与删除后的边不能进入答案。读取外部属性前先验证描述符并检查预算，页扫描、候选数、记录数和字节量也须纳入同一语句时钟与工作预算。

写入须先锁定排序后的端点，再读取源入口，防止在等待锁之前保存旧头地址。节点分块、邻接边、外部属性、入口元数据及三棵物理树，与现有属性索引和全文源事件共同发布；沿用外层语句标记，任何失败撤销本语句并保留用户事务此前的成功操作。大属性增长需要外部化时，同一事务同时替换描述符和属性块，保持边目录序号。

首次 v1/v2 迁移通过 `create_graph_physical_routes` 的原始事务回调实施，回调内不能嵌套 SQL 执行或再次打开 engine 写上下文。先构造完整的新邻接数据及路由，最后发布 manifest，并在同一事务删除旧权威拓扑记录；undo 必须让旧快照继续读取旧版本。显式用户事务中的迁移入口与普通 DDL 的限制须一致，不隐式提交用户已做的操作。旧段回收、并发交错和大图性能仍需单独验收。
