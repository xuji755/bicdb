# 图全文统计按查询词读取（2026-10-09）

后续当前态：v4 保留本节统计桶和查询路径，新增全语料预算及受管批次正文按需读取。旧格式首次维护完整升级到 v4；本文件保留 v3 阶段记录，当前维护行为见 [冷批次维护](bicdb_全文冷批次维护_20261009.md)。

此前 v2 已只加载候选文档，但 eventual 查询仍读取整个词汇表的统计页。本轮增加 v3，将统计按 `(db_type, 字段, channel, term)` 定位到原生记录，读取选中桶和校验路径，继续使用完整语料的 N、长度和 df 计算 BM25。源图写入仍只追加源事件，统计、分词和索引维护仍在 manual/batch 维护中完成。

## 记录及校验

- 沿用受保护的全文 heap 与唯一 ordinal B-tree，不添加远程索引服务。头格式 `bicdb-graph-fulltext-v3`，仍包含 definition、generation、covered_seq、documents、statistics_pages、statistics_sha256。最后两项在 v3 分别表示非空桶数和校验树根。
- 种类 2 的逻辑统计条目不变：`[domain, field, channel, N, length, term, df]`。依据完整编码键 SHA-256 的前 12 位路由至固定 4096 个桶；桶内按完整键排序并验证位置、唯一性和计数。哈希碰撞只共用存储桶，不能合并术语或域身份。每个桶按既有 checksum/chunk 编码存储。
- 非空桶构成固定深度 12 的稀疏 Merkle 树。空叶、非空叶和父节点使用不同的哈希输入域，缺省子树可推导。种类 3 保存非缺省节点，每 128 个树位置共用一份 checksummed JSON 页。全部统计和校验页参与原有共享 100 MiB 原生记录预算。
- 查询按词选桶，按兄弟节点选校验页，去重后经 ordinal B-tree 范围读取。逐桶重算叶与父节点，必须等于头中的根；整桶或整个校验页缺失不能直接当作合法空桶，仍须证明到根。即使攻击者重新计算局部记录 checksum，也不能通过旧根验证被修改的计数；旧代合法记录不能和新根拼接。
- 完整载入用于维护时还重建整棵树，与原生统计及校验记录逐项比对，再与完整文档重算的统计比对。查询局部图像校验所选词的局部 N、长度和 df 不超过全局统计，不允许发布或维护；它绑定字段定义、域、字段、channel 和规范化 query，不能用局部统计回答另一查询。

每词读取的是整个碰撞桶和若干共享校验页，不宣称“一词一个物理记录”。4096 桶是固定 v3 编码；集中碰撞仍可能增加桶大小和读取量，受分块、字节、token 与共享工作预算限制。当前仍没有针对大词库的完整延迟/吞吐验收。

## 兼容与诊断

- SQL/Cypher 的查询语法、评分公式、短语/精确模式、摘要、UTF-8 偏移、排序、域/字段过滤和源修订复核保持原语义。没有候选时不加载统计或文档；strict 使用当前源构建的统计，不读取旧代统计。
- v1 继续完整语料读取；v2 继续顺序统计页和候选文档读取。只读不会升级磁盘格式。SYNC、batch、WAIT 或 REBUILD 发布新代时使用 v3，与文档、倒排及 journal 确认同事务发布；既有索引对象号、源 journal 身份和维护策略保持原值。
- `SHOW FULLTEXT GRAPH INDEXES` 的原列顺序不变：storage_format 可为 v1/v2/v3；statistics_pages 在 v3 为非空统计桶数。
- `PROFILE CYPHER` 保留原十列，追加 `fulltext_statistics_records_loaded`，统计实际加载的统计和校验 checksum/chunk 行数。多次调用累加；不等于逻辑术语数或缓存页数，strict 和无候选为 0。所有这些原生行仍计入共享工作预算。

## 验证范围

核心测试覆盖三种检索 channel 的准确评分/摘要、1200 个无关域/词汇的局部读取、未请求记录损坏不影响局部查询、局部缺失/损坏/跨代混用/重新计算 checksum 的拒绝，以及确定构造的哈希碰撞不混淆术语。真实服务测试覆盖重启后的统计行读取量、与 strict 的逐值评分对照、陈旧源、WAIT、v1/v2 升级与只读不迁移。

最终日志、固定版本与部署校验见 [证据](evidence/bicdb-fulltext-keyed-statistics-20261009/README.md)。本阶段没有连接或修改 Neo4j，测试均使用独立合成 fixture，不更新生产索引或业务数据。

维护仍加载完整已发布语料并重算统计；v3 消除的是前台查询的全词汇统计读取。源图写入仍有整图暂存，旧段/陈旧键回收、专用邻接段、端点并发锁、受管引用、完整预算/部分结果协议和大型知识图谱性能验收仍需继续。100 MiB 是逻辑预算，不是 RSS 上限。
